# YaPlayer 🎵

A lightweight, modern, and privacy-focused desktop music player built in Rust and GTK4. Supports local MP3 playback, YouTube and Spotify streaming, automated downloading, real-time MPD/mpv IPC control, and a 10-band graphic equalizer.

## Features
- 🔍 Unified search across local files, YouTube, and Spotify.
- 🌌 Customizable desktop wallpapers support via GTK4 CSS.
- 🎛️ Built-in 10-band graphic equalizer powered by `mpv`.
- ⭐ Persistent favorites and history tracking.
- 📥 One-click and auto-download options for streaming media.

## Tech Stack
- **Language:** Rust
- **UI Toolkit:** GTK4
- **Backends:** `mpv` (playback), `yt-dlp` (streaming/downloading)
